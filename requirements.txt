# mzdesk/methods: Known methods page runs on numpy + rdkit only (already above). RepoRT (CC BY-SA 4.0) is an optional one-time download: `python -m mzdesk.methods.report_setup` needs git on PATH (sparse clone of github.com/michaelwitting/RepoRT, about 100 MB) and builds a ~40 MB local index; the JP18 data ships with the package.
# mzdesk/ms2: Library search runs on numpy + sqlite3 + matchms + ms_entropy (already above). The MassBank and GNPS libraries are an optional one-time download: `python -m mzdesk.ms2.library_setup [MassBank] [GNPS]` (about 140 MB + 2.2 GB download) builds a local mmap index (about 70 MB + 1.2 GB) in ~/.mzdesk/data/libraries/ (MZDESK_LIBRARY_DIR changes the folder); the raw files can then be deleted with --delete-raw.
# mzdesk/ms2: Structure prediction runs MS-FINDER v3.73 (RIKEN; program CC BY 4.0, source LGPL-3.0) through Mono, on the local version only (the online version has no Mono): no Python dependency. One-time install: `python -m mzdesk.ms2.msfinder_setup` (needs Mono, e.g. `brew install mono`; downloads about 325 MB from the official release and compiles the console front end from the project's own sources, pinned by SHA-256). `--check` only reports. MZDESK_MSFINDER_DIR (default ~/tools/msfinder/MSFINDER_v3.73) and MZDESK_MONO change the locations.
# mzdesk/ms2: De novo structure runs FRIGID-base (Coley group; code Apache-2.0, DLM checkpoint Apache-2.0, MIST checkpoint MIT) in its own PyTorch environment, on the local version only: no Python dependency in this file. One-time install: `python -m mzdesk.ms2.frigid_setup` (needs conda and git; about 3 GB download: PyTorch 2.6 environment with pinned wheels, the FRIGID code at commit 9a3e623, two checkpoints checked by md5). `--check` only reports. MZDESK_FRIGID_DIR (default ~/tools/frigid), MZDESK_FRIGID_DEVICE (auto | mps | cpu) and MZDESK_FRIGID_THREADS (CPU threads; default: the idle cores) change the folder, the device and the thread count. The driver and the SAFE length model (trained by us on MIT-licensed MassSpecGym labels) ship with mzDesk.
# mzdesk/orthogonal: CCS page. The CCSbase source data (c3sdb, MIT; all N2) is an optional one-time download: `python -m mzdesk.orthogonal.ccs_setup` needs git on PATH (sparse clone, about 5 MB) and builds a local index and model (about 4 MB) in ~/.mzdesk/data/ccs/ (MZDESK_CCS_DIR changes the folder). scikit-learn trains and runs the CCS prediction model (a few minutes at setup; the model is a local joblib file, never downloaded); `--skip-model` builds the index without it, then the page compares measured values only.
scikit-learn>=1.3

# Lipid Short Name

Give a lipid shorthand name. Get its LIPID+ and LIPID MAPS names and an illustrative structure.

## Results

### LIPID+

- Chains in descending carbon number, no sn positions. A level is — when the name does not give it.

### LIPID MAPS

- LIPID MAPS shorthand. A name is — when it cannot be written from this input; the ? gives the reason.

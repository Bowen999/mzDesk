# Dataset Finder

Find public datasets by sample metadata and ion polarity (GNPS2 Pan-ReDU).

## Inputs

- **Other filters (one column=value per line)**: Use Pan-ReDU column names; comma-separated values within a column are alternatives. Different columns are combined.

## Results

### Run notes

- Undetermined means at least one matched file has unreported polarity. It is not a confirmed match.

# Structure & Formats

Give up to three structures. Get 2D and 3D views and each structure as SMILES, InChI, InChIKey and MOL.

## Results

### Compounds

- One card per compound, with the 2D depiction and the 3D viewer in boxes of the same width and height, so the columns line up.
- With one compound the two boxes sit side by side; with two or three they stack in one column per compound.
- The 3D viewer shows one low-energy conformer (ETKDG + MMFF), not an ensemble; when the embedding fails the card keeps the 2D depiction.

### Structure formats

- Pick the compound above the format tabs; the same format stays selected when you switch.
